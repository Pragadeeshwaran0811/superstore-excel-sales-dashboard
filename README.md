# Superstore Sales Dashboard

## Project Overview
An Excel-based Data Analyst project analyzing Superstore sales and profit data.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Formulas
- Data Cleaning

## KPIs
- Total Sales
- Total Profit
- Total Quantity
- Total Orders

## Analysis
- Year-wise Sales & Profit
- State-wise Sales & Profit
- Category-wise Sales & Profit
- Region-wise Sales & Profit
- Segment-wise Sales & Profit
- Sub-Category-wise Sales & Profit

## Dashboard
The dashboard provides a visual overview of sales and profit performance.

## Key Skills Demonstrated
- Data Cleaning
- Data Analysis
- PivotTables
- Data Visualization
- Dashboard Creation
- Business Insights
